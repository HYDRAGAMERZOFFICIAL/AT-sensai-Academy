# Admission Process — Institution Input Required

Recommended workflow:
1. Enquiry / registration
2. Course selection
3. Eligibility confirmation
4. Counselling if applicable
5. Fee/payment
6. Admission confirmation
7. Batch allocation
8. Student onboarding

The exact process must be supplied and approved by AT Sensei Academy.

## Registration form
Collect only information necessary for the stated purpose.

Suggested fields:
- Full name
- Phone
- Email
- Class/qualification
- School/college where relevant
- Programme
- Preferred batch
- Parent/guardian details where required for minors
- Consent/acknowledgement
- Source/referral if genuinely needed

Do not collect sensitive information merely because a field is convenient.
