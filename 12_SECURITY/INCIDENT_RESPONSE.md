# Incident Response Plan

1. Detect
2. Contain
3. Preserve evidence/logs
4. Assess scope
5. Recover
6. Notify affected parties/regulators where legally required
7. Rotate credentials if necessary
8. Document root cause
9. Patch and verify
10. Conduct post-incident review

Maintain current contacts for:
- Institution owner
- Technical owner
- Hosting provider
- Payment provider
- Security contact
- Legal/privacy contact

Do not publish incident details before the institution's approved response process.
