# Data Retention Schedule — Institution Input Required

Create a row for each data category:
- Registration records
- Admission records
- Payment/invoice records
- Student academic records
- Parent/guardian consent records
- Marketing consent
- Contact enquiries
- Support tickets
- Analytics data
- Security logs
- Backups

For each row specify:
retention period → legal/business reason → deletion/anonymisation method → owner.

Do not keep data indefinitely “just in case”.
