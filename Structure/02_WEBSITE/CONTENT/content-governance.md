# Content Governance

## Source hierarchy
1. Institution-approved documents
2. Institution-approved updates
3. Supplied catalog as baseline
4. Website copy derived from approved sources
5. AI-generated copy only after factual verification

## Never invent
- Results
- Selection numbers
- Success percentages
- Testimonials
- Reviews
- Faculty credentials
- Awards
- Accreditations
- Government affiliations
- Scholarships
- Discounts
- Guarantees
- Course features
- Seat scarcity
- Salary claims

## Change-controlled content
Fees, dates, batches, timings, seats, course validity and contact details must be editable through an approved content process/CMS rather than scattered hard-coded values.

## Approval
Every public factual claim should have:
claim → source → approval status → approver → approval date.
