# Personal Data Inventory

For every field:
- Field name
- User type
- Source
- Purpose
- Required/optional
- Sensitive/high-risk classification where applicable
- Consent/notice requirement
- Storage location
- Who can access
- Processor/vendor
- Retention period
- Deletion method

Examples:
Name
Phone
Email
Class/qualification
School/college
Parent/guardian details where required
Registration data
Payment reference
Support messages
Consent records
Analytics identifiers where used
