# QA Checklist

## Functional
- Navigation works
- Registration works
- Validation works
- Duplicate submissions handled
- Email/notifications work
- Payment flow tested if enabled
- Admin authorization tested
- Mobile menu works
- Error/empty/loading states work

## Security
- Authorization tests
- Input validation
- Rate limiting
- File upload restrictions
- Secrets not exposed
- HTTPS
- Security headers
- Dependency scan
- Admin MFA where supported

## Privacy
- Consent capture works
- Privacy notice is accessible
- Data minimization verified
- Minor/guardian flow reviewed
- Retention documented
- Third-party processors documented

## Content
- Every claim has a source/approval
- Fees verified
- Timings verified
- Mentor details verified
- Contact details verified
- Testimonials have consent
- Images have rights/permissions

## Accessibility
- Keyboard navigation
- Visible focus
- Labels
- Contrast
- Alt text
- Reduced motion consideration
- Semantic headings

## Release
- Backup/rollback plan
- Monitoring
- Error tracking
- Domain/SSL
- Search Console/analytics configured only as approved
- Final institution sign-off
