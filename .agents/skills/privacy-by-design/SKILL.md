# Skill: Privacy by Design

Use whenever a feature touches personal data.

Workflow:
1. Identify data fields.
2. Identify purpose.
3. Minimize.
4. Determine legal/consent requirement.
5. Define access roles.
6. Define retention.
7. Define deletion/rights workflow.
8. Update DATA_INVENTORY.md and CONSENT_MATRIX.md.
9. Update privacy notice if needed.
10. Obtain approval for material changes.
