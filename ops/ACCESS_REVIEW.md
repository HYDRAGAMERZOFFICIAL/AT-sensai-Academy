# Access Review

Perform periodic review of:
- hosting;
- database;
- source repository;
- payment gateway;
- email;
- analytics;
- storage;
- domain/DNS;
- admin accounts;
- vendor dashboards.

For each user:
- role;
- access reason;
- last review;
- MFA;
- active/inactive;
- removal date if applicable.

Immediately remove access that is no longer required.
