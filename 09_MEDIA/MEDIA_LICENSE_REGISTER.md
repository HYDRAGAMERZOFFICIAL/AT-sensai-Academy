# Media & Asset Register

For every image/video/document:
- Asset filename
- Description
- Source
- Owner/licensor
- Permission/license
- Date obtained
- Scope of use
- Expiry, if any
- Attribution requirement
- Consent requirement
- Approved by
- Storage location

Do not use random Google images, copyrighted stock, AI-generated likenesses of real people, or student photos without appropriate rights/permissions.
